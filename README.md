📘 Project Overview- The Web-Based Inventory Management System (WBIMS), QuickTrack, is developed to address inventory
inefficiencies in Small and Medium-sized Enterprises (SMEs), focusing on real-time stock monitoring, user-role control, automated alerts, and intuitive dashboards.

🎯 Objectives
Design and build a responsive inventory management web application.

Enable real-time inventory tracking and reporting.

Facilitate user roles (Admin, Store Manager) with proper access controls.

Provide automated alerts for low stock and expiring products.

🔧 Tech Stack

Frontend: HTML, CSS, JavaScript

Backend: PHP (MVC architecture)

Database: MySQL

Server: Apache HTTP Server

Version Control: Git

Development Tools: Visual Studio Code, MySQL Workbench

🚀 Features
Secure authentication & role-based access

Real-time inventory tracking and updates

CRUD operations for inventory, sales, purchases

Notifications for stock level & expiration

Dashboard for Admin and Store Managers

PDF/CSV report generation

Responsive UI across devices

💡 Setup Instructions 
Clone the repository or copy the project files.

Set up Apache and MySQL (XAMPP recommended).

Import the database from database.sql (if available).

Update connect.php with your local DB credentials.

Run index.html via localhost in your browser.

🛡 Security
Passwords are encrypted.

Role-based access prevents unauthorized data manipulation.
